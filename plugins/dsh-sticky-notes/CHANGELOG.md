# Changelog · dsh-sticky-notes

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.12] - 2026-11-04

**修一个会让人完全看不到便签栏的回归**：0.1.10 改包名时漏改了浏览器半侧的 loader id。

### 修复

- `lib/client.js` 里 `__ModuleLoader__.load({ id })` 还写着改名前的短名 `dsh-sticky-notes`。
  Web 端是按**包名**（`@woshiwenjunjie/dsh-sticky-notes`）到模块表里取浏览器半侧的，
  取不到就静默跳过——面板整个不出现，控制台也没有报错，最难查的那种。
- 现在三处身份（loader id / 模块导出的 `name` / 失败兜底模块的 `name`）统一走一个
  `PKG_NAME` 常量，等于 `package.json` 的 `name`。`cordis.patch.yml` 的 `id: dsh-sticky-notes`
  保持不变——entry id 只是 profile 内的唯一键，跟模块 id 是两回事。

### 测试（这次的根因是测试本身写死了旧值）

- `test/smoke.mjs` 的身份断言改为**从 `package.json` 读包名**，并同时断言模块 `name`；
  把短名放回去，两条断言立即失败（已反验）。
- `templates/plugin/lib/client.js` 同步这个写法，避免下一个插件再踩。
- `docs/plugin-authoring.md` 的常见坑表加一行：改名后浏览器半侧静默不加载。

### 注意

改完必须**重装**才生效（安全模式列表里的升级/重装，或走插件市场）。
不要去改 `node_modules` 下那份：它指向 `.generations/live/...`，每次启动重建。

## [0.1.11] - 2026-11-04

主题：**顺序由你决定**。便签从「按时间自动排」变成「可以手动排」，最后一块「理所当然」的能力。

### 新增

- **拖动排序**：卡片左边缘有一个把手（hover / 键盘聚焦时显现，平时隐形），拖到目标位置松手即可。
  落在目标卡片上半部分插到它前面、下半部分插到它后面。
- **键盘等价操作**：把手聚焦后按 `↑` / `↓` 移动一格——不用鼠标也能排。
- **重排：按最近改动**：`⋯` 菜单里的兜底项，手动排乱了点一下就按时间复位（置顶组仍在上面）。
- 拖动过程**零 React 重渲染**：拖起只记一个 ref，高亮/半透明直接改 DOM class，
  松手才提交一次顺序。拖 500 条也不会因为 rerender 掉帧。

### 变更（语义）

- **编辑不再改变顺序**。以前失焦会把刚改的便签顶到最上面，现在顺序是「你排的」，
  编辑只更新「最近改动」时间与时间戳显示。这是手动排序的必要前提——否则一编辑就把手动顺序打乱。

### 兼容

- 便签数据新增 `order` 字段（升序 = 从上到下）。**老数据不迁移**：读取时按 `-updatedAt` 兜底，
  正好等价于以前「最近改动在前」的排序，用户无感。
- 新便签 `order = min - 1`，永远落在最上面，不管之前怎么排过。
- 导出备份包含 `order`，恢复后顺序一致。

### 测试

`test/behavior.mjs` 新增：拖到下半部分插到后面、拖到上半部分插到前面、`↑`/`↓` 移动一格、
落盘 `order` 与视觉顺序一致、手动排过之后新便签仍落最上面、`⋯`→「重排」复位成时间序。
把 `dropOn` 改成空操作，这些断言立即失败。

## [0.1.8] - 2026-11-04

主题：**半句话也不会丢**。两个都很小，但都是日常真的会碰到的「算了，重打一遍吧」时刻。

### 新增

- **草稿实时落盘**：还没按「记下」的内容写进 `dsh-sticky-notes:draft`。
  刷新页面、重装插件、手滑关掉页面回来还在；按「记下」后立即清掉，不留垃圾。
- **一键复制**：每条便签一个复制按钮，写进系统剪贴板。按钮平时是隐形的
  （`opacity:0`），鼠标进卡片或键盘聚焦时才浮现——静态列表不多一排图标。
- 复制成功提示「已复制这条便签」；剪贴板不可用（权限被拒 / 非安全上下文）时如实报错
  「复制失败，请手动选择文本」，**不假装成功**。

### 实现要点

- 草稿用一个独立 key，和便签内容 / 面板开合分开：草稿是「当前这一页正在写什么」，
  不该参与多标签页同步。
- 复制走 `navigator.clipboard.writeText`（`127.0.0.1` 属于安全上下文，可用）；
  失败分支和成功分支各给一条提示，复用底部提示条通道。

### 测试

`test/behavior.mjs` 新增：草稿写盘 → 重新挂载（相当于刷新）后还在 → 记下后清掉；
复制把正文写进剪贴板并提示；剪贴板拒绝时给红色错误提示。
测试台补上了 `localStorage.removeItem` 与可控的 `navigator.clipboard`。

## [0.1.7] - 2026-11-04

主题：**搜索命中看得到**。上一版让搜索能搜到归档便签，这一版让你一眼看到命中在哪。

### 新增

- **命中片段高亮**：搜索时卡片正文切成「只读 + `<mark>` 高亮」渲染——textarea 里画不了 `<mark>`，
  所以这是一个必须的形态切换，而不是多加一层装饰。
- **点一下就编辑这一条**：点只读正文把**这一条**切回 textarea（自动聚焦），其余保持只读高亮，
  搜索词不变。清空搜索后所有卡片回到常态 textarea，高亮随之消失。
- 归档便签在搜索态仍是纯只读（没有可点击/可聚焦的按钮语义），不会假装能编辑。

### 实现要点

- 高亮是把正文按关键词 `split` 成 `[普通, 命中, 普通, …]`，命中段单独包 `<mark>`；
  关键词做正则转义，大小写不敏感；换行靠 `white-space:pre-wrap` 保留。
- `mark` 用中性半透明灰（`rgba(127,127,127,.3)`）+ 加粗，浅色/深色主题都不用另配颜色。
- 「哪条在编辑」是父组件的一个 `editingId` state，`onStartEdit` 用 `useCallback([])` 保持引用稳定，
  不破坏 0.1.5 的卡片 memo。

### 测试

`test/behavior.mjs` 新增：搜索态下没有 textarea、`<mark>` 文本等于关键词、命中条数正确、
归档命中项没有可点击语义、点一条只切回那一条（带 autoFocus）、清空搜索后无残留高亮且全部回到 textarea。

## [0.1.6] - 2026-11-04

主题：**便签知道自己在哪个会话里**。这是只有 DSH 插件才做得到的一件事——别的便签工具拿不到会话上下文。

### 新增

- **新便签记下所在会话**：`sessionId` 落进便签数据，导出/导入一并保留。
- **「本会话」筛选**：过滤条变成 `全部 / 本会话 / 已归档`，只看在当前会话里写下的便签。
  切换会话时该视图自动跟着变。
- **拿不到会话就自动降级**：如果 slot 没送来标准 kit（或版本换代后接口变了），
  「本会话」标签不出现，便签栏仍是一个纯本地便签工具——不会残一个点了没反应的按钮。
- 老便签没有 `sessionId`，只出现在「全部」里，**不强制迁移**。

### 实现要点

- slot 注册的组件现在会被转发整套标准 props（`Object.assign({}, slotProps, { locale })`）；
  之前只取了 `locale`，把 `useSessions` 这类 selector hook 丢掉了。
- 「当前会话」用官方同一套判据：`useSessions(state => Object.values(state.byId)
  .find(s => (s.retainedBy.mainView ?? 0) > 0)?.id)`——与 `dsh-client-ui-layout` 的
  `DocumentTitle` 完全一致（该结论来自读 0.2.1-rc.2 的 client bundle）。
- hook 顺序稳定：有 kit 时调 kit 的 selector hook，没有时退回 `useState(null)`，
  两条分支都只占一个 hook 槽位。

### 测试

`test/behavior.mjs` 用模拟 kit（`useSessions` 返回可切换的会话快照）断言：新便签记下当前会话、
切会话后新便签换 id、切回来自动更新「本会话」视图、计数正确、无 kit 时只有 2 个标签。

## [0.1.5] - 2026-11-04

主题：**先量再改**。列表最多 500 条，之前每敲一个字都会把整张列表重渲染一遍。

### 性能

- **卡片 memo 化**：`NoteCard` 改成 `memo(NoteCard)`，并把 `t` / `timeLabels` / 7 个回调
  （更新、落盘、换色、置顶、归档、恢复、删除）全部 `useMemo` / `useCallback` 稳住引用，
  否则浅比较每次都会失败、memo 形同虚设。回调不再闭包 `store`，需要「当前列表」时读
  `latestStore` ref。
- 结果：打字时**只有正在编辑的那 1 张卡片重渲染**，其余按 props 跳过。

同一套测法（`test/perf.mjs`，假 React 里 `memo`/`useMemo`/`useCallback` 有真语义）改前改后对比：

| 便签数 | 一次重渲染构造的元素 | 一次重渲染耗时 |
|---|---|---|
| 100 | 2053 → **50** | 0.56ms → **0.10ms** |
| 300 | 6053 → **50** | 1.62ms → **0.21ms** |
| 500 | 10053 → **50** | 3.42ms → **0.35ms** |

诚实的边界：这是 Node 里量「构造 JSX 元素」的成本，**没有量浏览器端的 DOM diff/commit**；
真实打字成本 = 父组件 + 1 张卡片，所以上表是下限收益，不是浏览器里的绝对耗时。

### 测试

- 新增 `test/perf.mjs`（`npm run perf`）：可用第二个参数指定客户端文件路径，直接对比任意两个版本。
- `test/behavior.mjs` 的迷你 React 补上 `memo` / `useMemo` / `useCallback` 的真语义，
  并断言「打字只重渲染 1 张卡片」——去掉 memo 这条会立刻失败。

## [0.1.4] - 2026-11-04

主题：**丢不了**。之前只有导出、没有导入，等于备份只能看不能还原——这是最后一个数据安全缺口。

### 新增

- **备份（JSON）与恢复**：`⋯` 菜单里两个动作。备份文件保留 id / 颜色 / 置顶 / 归档 /
  时间戳全部字段，导回去一模一样；Markdown 导出继续只负责给人看。
- **按 id 合并，不静默覆盖**：同 id 取 `updatedAt` 较新的那份，新 id 追加；提示条报
  「已导入 N 条 · 更新 M 条」。
- **导入可撤销**：5 秒内点撤销整份换回导入前的列表（复用删除的撤销通道，一个通道三种文案：
  删除了 / 导入了 / 出错了）。
- **认不出文件就明确报错**：不是备份文件、或备份里没有便签，都只提示、一个字节都不动现有数据。

### 界面

- 头部按钮数量不变：备份与恢复收进 `⋯` 菜单（低频操作不占常态位置）。
- 菜单点外面 / Esc 收起，`Esc` 的优先级是「先关菜单，再清搜索，最后收面板」。

### 测试

`test/behavior.mjs` 新增：导出 → 清空 → 导入的逐字段 round-trip、同 id 取新、新 id 追加、
撤销回滚、非法文件与空备份不动数据。测试台的定时器改成虚拟时钟（`advance(ms)`），
这样 300ms 去抖落盘和 5 秒撤销窗口都能被测到，而不是一调度就被执行掉。

## [0.1.3] - 2026-11-04

主题：**找得回**。便签最痛的失败是「找不到」，这版本把两个堵点各挪开一点。

### 修复

- **搜索覆盖全部便签（含已归档）**：以前搜索只在当前视图里过滤，归档的便签必须切到「已归档」再搜一次。

### 改进

- **收起面板后焦点回到左边缘标签**：键盘用户按 `Esc` 收起时焦点不再掉到页面开头；
  点面板外面收起时不抢焦点（不打断用户刚点的那一处）。

### 测试

- `test/behavior.mjs` 新增：搜索跨视图命中已归档、命中的归档项只读、标签高亮一致性、收起后焦点归还。
  两处都用「把修复回退成旧写法，测试必须失败」验过不是空断言。

## [0.1.2] - 2026-11-04

「用着用着才会发现」的三个问题，都是一行到十行级别的改动，但直接影响手感。

### 修复

- **编辑时卡片不再跳到列表顶部**：原先每次按键都把 `updatedAt` 刷成当前时间，
  而列表按 `updatedAt` 降序排——改第 5 条便签，敲第一个字它就被顶到最上面，滚动位置跟着跳。
  改为「打字过程中不动排序，失焦时才更新最近改动」，且只点进去、没真改过的点击不算改过。
- **存储失败时不再谎报「已保存」**：`writeNotes` 改为返回成败，写失败（localStorage 满或被禁用）
  时提示条改为红色的「保存失败，请先导出」并带 `role="alert"`，
  恢复可写后自动回到「已自动保存到本机」。
- **中文输入法组词时按回车不再误存**：`Ctrl/Cmd + Enter` 现在会先判断 `isComposing`，
  输入法选词期间按回车只选词，不会把半句话存成便签并清空草稿。

### 测试

- 新增 `test/behavior.mjs`：迷你 React（`useState` 真存状态并重渲染、`useEffect` 按依赖执行），
  驱动真实组件验证上面三条——修复前跑会失败，修复后通过。
- `node scripts/check.mjs` 现在会跑 `test/` 下所有测试；`npm test` 跑 smoke + behavior 两个。

## [0.1.1] - 2026-11-04

### 修复

- **语言服务不再拖垮插件**：`locale` 从 `inject` 里移除，改为 `ctx.get('locale')` 惰性探测；

## [0.1.0] - 2026-11-04

首个公开版本。三轮迭代（P0/P1/P2）合并为一次发布。

### 新增

- 左侧便签栏：会话列表右边缘的竖排「便签」标签，点开为 300px 抽屉；`Alt + Shift + N` 全局开关。
- 快速记录：`Ctrl/Cmd + Enter` 记下；每条便签可原地编辑、换色、置顶、删除、归档。
- 搜索：便签 ≥ 6 条时出现搜索框，`Ctrl/Cmd + K` 聚焦，`Esc` 先清搜索再收起。
- 撤销：删除后 5 秒内可撤销（`aria-live` 提示），替代「点两次确认」。
- 归档：归档 / 恢复 + 「全部 / 已归档」过滤，归档便签置灰只读。
- 导出：全部便签导出为 Markdown，文末附本机使用统计。
- i18n：接入 DSH locale（zh / en，其余语言按 en 回退），语言切换即时生效。
- 本机埋点：打开 / 新建 / 编辑 / 删除 / 撤销 / 置顶 / 归档 / 恢复 / 导出 / 搜索。

### 可用性

- 命中区：换色按钮 24×24、删除 28×28、头部图标 32×32，均达 WCAG 2.2 AA 24px 底线。
- 对比度：暗色主题下品牌按钮由「白底白字 1.05:1」修正为反色文字 15.03:1；提示文字 / 时间戳浅色 5.80、深色 10.42。
- 遮挡：面板贴在会话列表右边界展开（量 `[data-dsh-sidebar-root]` + `ResizeObserver`），不再遮挡会话列表，且移除全屏遮罩。
- 图标：换用 DSH primitives 的 Fluent 图标，取不到时回退手绘 SVG。
