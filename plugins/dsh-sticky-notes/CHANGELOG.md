# Changelog · dsh-sticky-notes

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.0] - 2026-11-04

首个公开版本。三轮迭代（P0/P1/P2）合并为一次发布。

### 新增

- 左侧便签栏：会话列表右边缘的竖排「便签」标签，点开为 300px 抽屉；`Alt + Shift + N` 全局开关。
- 快速记录：`Ctrl/Cmd + Enter` 记下；每条便签可原地编辑、换色、置顶、删除、归档。
- 搜索：便签 ≥ 6 条时出现搜索框，`Ctrl/Cmd + K` 聚焦，`Esc` 先清搜索再收起。
- 撤销：删除后 5 秒内可撤销（`aria-live` 提示），替代「点两次确认」。
- 归档：归档 / 恢复 + 「全部 / 已归档」过滤，归档便签置灰只读。
- 导出：全部便签导出为 Markdown，文末附本机使用统计。
- i18n：接入 DSH locale（zh / en，其余语言按 en 回退），语言切换即时生效。
- 本机埋点：打开 / 新建 / 编辑 / 删除 / 撤销 / 置顶 / 归档 / 恢复 / 导出 / 搜索。

### 可用性

- 命中区：换色按钮 24×24、删除 28×28、头部图标 32×32，均达 WCAG 2.2 AA 24px 底线。
- 对比度：暗色主题下品牌按钮由「白底白字 1.05:1」修正为反色文字 15.03:1；提示文字 / 时间戳浅色 5.80、深色 10.42。
- 遮挡：面板贴在会话列表右边界展开（量 `[data-dsh-sidebar-root]` + `ResizeObserver`），不再遮挡会话列表，且移除全屏遮罩。
- 图标：换用 DSH primitives 的 Fluent 图标，取不到时回退手绘 SVG。

### 说明

- 数据只存本机 localStorage，不经 Host、不上报。
- 兼容性只在此版本实测过 DSH `0.2.1-rc.2`。
